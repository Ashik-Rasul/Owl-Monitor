Automated Response Architecture Transparency

Owl Monitor triggers automated firewall responses exclusively when a Sigma rule configured with action: block_ip is matched (e.g., SSH Brute Force, Port Scanning, SYN Flood, ARP Spoofing). When running with root/sudo privileges on Linux, the system executes iptables -A INPUT -s <IP> -j DROP. On environments without root or on non-Linux hosts, the SOAR responder logs the mitigation and flags the IP in the dashboard while transparently documenting privilege constraints.
